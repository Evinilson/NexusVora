# Registo diário de leads

Cada execução da tarefa automática de prospeção deve criar neste diretório um ficheiro com o formato `AAAA-MM-DD.md`.

Consultar [../DAILY_PME_MAPS_RESEARCH.md](../DAILY_PME_MAPS_RESEARCH.md) antes de pesquisar. Cada ficheiro deve conter apenas os 5 novos leads do dia e indicar a respetiva origem Google Maps.

O ficheiro `lote-inicial-2026-07-30.md` é uma consolidação histórica da lista inicial e não corresponde a uma execução diária.
